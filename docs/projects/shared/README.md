# Alcance Compartido

## Proposito

Contenedor para servicios, reglas o capacidades compartidas entre soluciones.

Usar esta vista cuando un artefacto no pertenece exclusivamente a SST,
`4uentes-portfolio` u otro producto futuro.

## Servicios Compartidos

- [4uentes-auth](../../apps/4uentes-auth.md)
- [4uentes-ards-core](../../apps/4uentes-ards-core.md)

## Reglas Compartidas

- [solutions-model](../../cross-repo/solutions-model.md)
- [control-plane-scope-partition](../../cross-repo/control-plane-scope-partition.md)
- [human-doc-language](../../policies/human-doc-language-policy.md)

## Criterio

Un shared service no pertenece de forma oculta a una solucion. Se referencia
desde las soluciones consumidoras y conserva su identidad canonica propia.
