# Seccion Apps

## Proposito

Esta seccion agrupa documentacion cuyo dueno principal es un servicio logico o
un repositorio canonico.

## Usar Esta Seccion Para

- notas por repo/app
- analisis de workflows por app
- notas de contrato de deployment por app
- notas de adopcion de capabilities por app

- `sst-bend`
