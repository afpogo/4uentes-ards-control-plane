# Etiquetas De Evidencia De Proyectos - CR-4UENTES-0012

## Decision

Este CR aplica la taxonomia adoptada por `CR-4UENTES-0011` a los proyectos
visibles del portfolio.

Los dos proyectos actuales tienen repositorio GitHub publico, pero sus
descripciones los presentan como practica tecnica. Por eso quedan clasificados
como `demo_or_learning`, con fuente `public_github_repository`.

## Clasificacion Aplicada

- `SocketServerBasic-react-nodeExpress`: `demo_or_learning`.
- `VoteForBands`: `demo_or_learning`.

## Guardrails

- La etiqueta visible no implica uso productivo, cliente ni impacto enterprise.
- GitHub se usa como link publico existente, no como enrichment revisado.
- La revision GitHub con allowlist explicita queda pendiente para otro CR.
- Experiencia laboral y contacto publico quedan fuera de alcance.
