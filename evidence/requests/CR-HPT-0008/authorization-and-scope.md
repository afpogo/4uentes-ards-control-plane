# CR-HPT-0008 — autorización de ejecución

Fecha: 2026-08-22

El usuario aprobó explícitamente la propuesta registrada en el plan. Quedan
autorizados PostgreSQL, SQLAlchemy 2, Alembic, psycopg 3, cantidades decimales
con unidad, condiciones durables declaradas, valorización prudente de
desperdicio y un puerto `PrincipalContext` fail-closed.

La implementación no puede aceptar owner/account desde body, query o headers
del navegador. Los tests pueden inyectar un principal confiable; producción no
tendrá fallback inseguro mientras el adapter SST siga pendiente.

Continúan fuera de alcance instrumentos de mercado, cripto, broker execution,
OCR, IA, recomendaciones, scores subjetivos, costo monetario de demora,
infraestructura y cambios en repos SST.
