# CR-SST-0112 - Resumen De Intencion

## Objetivo

Definir la experiencia de entrada de texto anotable antes de implementar
runtime. La superficie debe sentirse como una hoja/editor donde el usuario
escribe, pega o importa texto y luego selecciona fragmentos para asignar tags,
relevancia y configuraciones.

## Intencion Principal

- Hoja editable como centro de la experiencia.
- Seleccion con mouse de lineas, parrafos, rangos, bloques o texto manual.
- Menu flotante/contextual para aplicar `LearningContentTag` y relevancia.
- Vista previa anotada antes de aceptar.
- Render posterior tipo Markdown o template visual.
- Separacion estricta entre `ArticleTag` y tags de contenido.

## Resultado Esperado

Contrato UX listo para implementar CR-SST-0113 y CR-SST-0114.
