# CR-4UENTES-0020 - Analisis De Experiencia Actual

## Hallazgos

La seccion de experiencia ya contiene una base valiosa: trayectoria enterprise,
integraciones, middleware, SOA, fullstack, React, Java/Spring, CI/CD y soporte a
entrega de producto. El problema principal no es falta de experiencia, sino que
parte del copy todavia se lee como historial operativo.

## Riesgos Detectados

- Las cards muestran direcciones exactas de oficinas de empresas. Para
  publicacion amplia conviene usar ubicacion general.
- Algunos logros describen tareas, pero no siempre explican el valor profesional:
  tipo de problema, contexto, contribucion, evidencia y stack.
- La narrativa debe servir como fuente para revalidar el CV, por lo que no debe
  inventar metricas ni ownership no aprobado.

## Intencion Del Corte

Este CR mejora el copy visible para que la experiencia comunique:

- recorrido desde middleware/SOA hacia fullstack/product delivery;
- capacidad de integracion y lectura de contratos;
- colaboracion con negocio, producto, equipos externos y equipos tecnicos;
- criterio tecnico en entornos enterprise;
- evidencia reusable para un CV sanitizado.
