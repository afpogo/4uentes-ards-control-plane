# CR-4UENTES-0034 - Plan De Implementacion

Fecha: 2026-07-07

## Objetivo

Mejorar el primer impacto del Portfolio para que un recruiter o revisor
profesional entienda rapidamente:

- quien es el usuario;
- que tipo de valor profesional expone;
- que acciones primarias puede tomar;
- que el CV sigue gobernado por una politica de publicacion/sanitizacion.

## Scope

Incluye:

- Home/Hero.
- Jerarquia de CTA.
- Copy breve de posicionamiento.
- Ajustes visuales directamente necesarios para la primera pantalla.
- Owner docs/specs del repo hijo.

No incluye:

- Activar descarga de CV.
- Reescribir experiencia completa.
- Rehacer proyectos o skills.
- Remediar secciones mobile de forma amplia.
- Agregar backend, BFF, auth, analytics o GitHub fetching runtime.

## Owner Enforcement

El repo hijo debera actualizar docs/specs en el mismo lifecycle:

- `docs/portfolio-intent.md`
- `docs/architecture/README.md`
- `docs/qa/visual-checklist.md`
- `specs/features/00-index.yaml`
